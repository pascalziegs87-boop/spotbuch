# Spotbuch

Eigene Foto-Location-App für Fotografen: Spots auf der Karte, Referenzfotos mit Kameradaten,
goldene/blaue Stunde, Parkplatz, Regen-Alternative, Backup.

Nutzung: Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
Alle Spots und Fotos liegen nur lokal auf dem Gerät (IndexedDB) – regelmäßig Backup machen.
